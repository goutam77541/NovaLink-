# NovaLink — Multi-Service Affiliate Website

A premium, responsive 3-page affiliate directory starter. The project uses plain HTML, CSS and JavaScript and is suitable for GitHub Pages.

## Files
- `index.html` — Homepage
- `services.html` — Tool directory and category sections
- `about.html` — About, contact, affiliate disclosure and setup information
- `style.css` — Responsive premium-modern styling
- `script.js` — Mobile navigation and automatic footer year
- `affiliate-links.js` — Central configuration for approved affiliate links

## Before you publish
1. Replace `YOUR-EMAIL@example.com` in `about.html` with an email address you control.
2. Edit `affiliate-links.js` and add only exact affiliate URLs supplied by programs that approved your account.
3. Review every tool description and remove listings you do not want to recommend. Example listings are not endorsements.
4. Test all navigation and configured affiliate links on your phone.
5. Keep the affiliate disclosure visible. If you later add tracking, analytics or collect personal data, update the privacy information appropriately.
6. Consider whether the name NovaLink is available and suitable before investing in branding or a custom domain.

## Publish on GitHub Pages from Android
1. Download and extract `NovaLink-Website.zip` on your Android phone.
2. In GitHub, create a new repository named `novalink` (or another available name).
3. Open the repository. Use **Add file → Upload files** if available. If it is hidden on mobile, in Chrome tap `⋮` and enable **Desktop site**, then reload the repository page.
4. Upload the six files from the extracted `NovaLink` folder to the repository root—not the enclosing folder.
5. Scroll down and tap **Commit changes**.
6. Open **Settings → Pages**. Under Build and deployment, select **Deploy from a branch**, choose branch `main` and folder `/(root)`, then save.
7. Wait for GitHub Pages to publish. Open the URL shown in the Pages settings. For a repository named `novalink`, the project URL usually looks like `https://YOUR-USERNAME.github.io/novalink/`.
8. Test Home, Explore Tools, About, mobile navigation and all configured links.

The exact GitHub interface may vary on Android. Never upload passwords, private keys or other secrets to a public repository.
